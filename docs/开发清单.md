# ServerProbe 服务探针管理系统 — 开发清单

> 组成：**Android 管理端 App**（Kotlin + Jetpack Compose）+ **服务器探针 Agent**（Go，纯标准库，单二进制）
> 技术选型原则：简洁高效 —— App 用 Kotlin/Compose/Material3 声明式 UI；探针用 Go 零依赖交叉编译，`curl | bash` 一键安装。

## 架构总览

```
┌─────────────────┐   HTTPS(自签+Token)   ┌──────────────────┐
│  Android App    │ ───────────────────▶ │  Go 探针 Agent    │
│  Compose UI     │   GET /api/v1/*      │  systemd 常驻     │
│  sshj SSH客户端 │ ◀─────────────────── │  /proc 采集       │
└─────────────────┘   SSH:22 终端直连     └──────────────────┘
```

- App ↔ 探针：HTTPS + `Authorization: Bearer <token>`（常量时间比较），自签证书支持 SHA-256 指纹锁定
- App ↔ 服务器：sshj 直连 SSH（密码 / 私钥），独立于探针，可绑定为探针主机的"快捷身份"

## 安全防护清单（授权认证）

| 项 | 措施 |
|---|---|
| 探针认证 | 随机 32 字节 Token，`subtle.ConstantTimeCompare` 常量时间校验，仅认 `Authorization` 头 |
| 传输加密 | 默认强制 TLS（自签 ECDSA P-256），App 支持证书指纹锁定；未锁定时 TOFU 提示确认 |
| 限流防爆破 | 探针端每 IP 令牌桶限流（默认 120 次/分），失败计数，超限 429 |
| 服务控制 | 写操作（start/stop/restart）独立开关 `allow_service_control`，服务名白名单正则校验，exec 数组传参防注入 |
| 凭据存储 | App 内密码/私钥经 Android Keystore AES-256-GCM 加密后入库，明文不落盘 |
| 备份文件 | 导出备份需用户口令 PBKDF2-HMAC-SHA256(210000) 派生密钥 + AES-GCM 加密 |
| App 加固 | `allowBackup=false`、网络拒绝明文流量（除非单主机显式允许）、生物识别锁屏、截屏不敏感处理 |

- [x] 环境：JDK 17 / Android SDK 35-36 / Go 1.25 / Maven+Google 仓库可达
- [x] 目录：`ServerProbe/probe`（Go 探针）、`ServerProbe/app-android`（App）

## 阶段 1｜Go 探针 Agent

- [x] 采集器：CPU（总量+每核）、内存/交换、多磁盘挂载点、网卡实时速率、负载、进程数、运行时长、OS/内核
- [x] 服务状态：systemd 服务列表与状态（load/active/sub/描述）
- [x] API：`/api/v1/info`、`/api/v1/status`、`/api/v1/services`、`/api/v1/services/action`(POST)
- [x] 认证：Bearer Token 常量时间比较；限流；请求超时与体积上限；安全响应头
- [x] TLS：自签证书生成（`serverprobe init`），输出 SHA-256 指纹供 App 锁定
- [x] CLI：`init`（生成配置/Token/证书）、`serve`、`version`
- [x] 部署：`install.sh`（架构识别、专用用户、systemd unit、开机自启）+ 交叉编译 linux/amd64、arm64
